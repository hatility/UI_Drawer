## [0.3.0] - 2026-11-12

이름 카드를 두 배로 늘리고, 모바일 체험을 더했어요.

### 더함
- **이름 카드 77장 → 150장**: 모든 서랍에 고르게 (카드마다 Stageshow 방식 그림)
  - 알림 · 로딩: 콜아웃, 푸시 알림, 완료 화면, 원형 프로그레스, 낙관적 UI, 스플래시 …
  - 입력: 플로팅 라벨, 인증번호 입력칸, 태그 입력, 콤보박스, 타임 피커, 컬러 피커 …
  - 이동 · 콘텐츠: 앱 바, 내비게이션 레일, 단계 표시, 커맨드 팔레트, 메이슨리, 라이트박스, 칸반, 스토리, 하단 고정 버튼 …
  - 디자인 스타일: 오로라, Y2K, 스위스, 멤피스, 픽셀 아트, 손그림, 그레인, 아이소메트릭
  - 제스처 · 아이콘 · AI · 다크 패턴: 더블 탭, 스크롤 스냅, 러버밴드, 그래버, 셰브론, 입력 중 표시, 캔버스 패널, 몰래 자동 결제 …
- **체험관 모바일**: Stageshow Phone 안의 진짜 앱 — 당겨서 새로고침, 밀어서 삭제(실행 취소), 꾹 눌러 메뉴, 사진 두 번 탭, 바텀시트 끌어 내려 닫기, 햄버거 메뉴, 스토리, 스크롤 스냅, 탭 바
  - 사이트 스타일 · 이름표가 모바일에도 그대로 먹어요
  - 모바일 카드에서 ‘체험관에서 보기’를 누르면 모바일 화면으로 바로 열려요

### 바꿈
- 이름표 · 반짝 표시를 PC · 모바일이 함께 쓰도록 한 곳(labels.tsx)으로 모았어요
- 좁은 화면에서 체험관 도구 줄이 두 줄로 접혀요

## [0.2.0] - 2026-11-12

머티리얼 3로 전체 개편하고, 화면과 흐름을 단순하게 줄였어요.

### 바꿈
- **사이트 전체 머티리얼 3**: 색 역할(primary · surface-container …), 모양, 글자 크기, 상태 레이어를 M3 규칙으로
- **화면 단순화**: 머리줄 · 서랍장 그림 · 카드 번호 · 힌트를 없애고, 왼쪽 **내비게이션 드로어** 하나에 서랍과 체험관을 모았어요
- **이름 카드**: 그림 + 이름 + 영어 이름만 (M3 filled card)
- **상세 창**: M3 사이드 시트로 — 설명 · 이럴 때 써요 · 헷갈리는 친구 · 체험관에서 보기
- **체험관**: 오른쪽 패널을 없애고 도구 줄 하나(방금 본 UI · 사이트 스타일 · 이름표)로
- **첫 화면 그림 (Stageshow)**: 하트 → 스낵바 → 이름표 → 사이드 시트 → ‘실행 취소’로 처음으로 돌아가는 장면

### 더함
- **디자인 스타일 서랍** 10장: 머티리얼 · 플랫 · 스큐어모피즘 · 뉴모피즘 · 글래스모피즘 · 클레이모피즘 · 뉴브루탈리즘 · 미니멀리즘 · 벤토 그리드 · 다크 모드
- **체험관 스타일 바꾸기**: 가상 빵집을 머티리얼 · 플랫 · 글래스 · 뉴모피즘 · 브루탈 · 다크로 바로 바꿔 보기

## [0.1.0] - 2026-11-12

첫 초안이에요.

### 더함
- **서랍장(사전)**: 9개 서랍, 이름 카드 67장. 카드마다 Stageshow 방식 미리보기 그림 (마우스를 올리면 움직여요)
- **찾기**: 한국어 이름 · 영어 · 다른 이름 · 초성(ㅌㅅㅌ) · 모양 설명(‘아래에서 올라오는 창’)으로 찾기, `/` 키로 바로 찾기
- **상세 드로어**: 옆에서 밀려 나오는 설명 창 — 이럴 때 써요, 헷갈리는 친구, 체험관 바로가기
- **체험관**: 가상의 빵집 사이트 ‘몽글 베이커리’에서 40가지 넘는 UI를 직접 눌러 보기
  - 이름표 켜기: 화면 위 모든 UI에 이름이 붙고, 누르면 사전이 열려요
  - 보여 줘: 이름을 고르면 그 UI가 직접 움직여요
  - 방금 본 UI: 사이트를 쓰다 뜬 UI의 이름이 쌓여요
- 첫 화면 그림: Stageshow Stage 로 그린 ‘토스트 이름표가 서랍에 들어가는’ 장면
- Docker: `docker compose up -d --build` 로 바로 띄우기 (nginx 하나)
