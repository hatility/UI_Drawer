# 변경 기록

## [0.6.0] - 2026-11-20

### 더함 · 바이브 코딩 프롬프트
- **AI에게 만들어 달라고 하기**: 카드 상세 창 › 만들기 탭에서 그 UI를 정확히 만들어 달라는 프롬프트를 복사해요. Claude · ChatGPT · Cursor 같은 곳에 붙여 넣으면 돼요.
  - 카드에 이미 있는 내용으로 만들어서 837장 모두 쓸 수 있어요: 무엇인지, 이럴 때 쓰는지, 헷갈리는 짝(예: ‘토스트가 아니야, 버튼이 꼭 하나 있어야 해’), 잘 만드는 법, 피할 실수, 접근성, 다른 곳에서 부르는 이름.
  - 자주 쓰는 카드 30장(토스트 · 스낵바 · 모달 · 바텀시트 · 탭 · 토글 등)은 꼭 지켜야 할 동작을 직접 적어 더 정확해요.
  - 기술은 React · HTML · Vue · SwiftUI · Flutter, 길이는 자세히 · 짧게 중에서 골라요. 고른 것은 기억해요. ‘어떤 글이 복사되나요?’를 펼치면 미리 볼 수 있어요.
- **화면 통째로 만들어 달라고 하기**: 나란히 비교에 담은 카드나 내 서랍 폴더의 카드로, 화면 하나를 만들어 달라는 프롬프트를 한 번에 복사해요.
- 사이트 안에서 AI를 직접 부르지는 않아요. 가입 · API 키 없이 프롬프트만 복사해요.

### 바꿈 · 카드 상세 창을 덜 복잡하게
- 위쪽은 이름 · 영어 이름 · 단계를 한 줄에 두고, 다른 이름(별칭)은 더 알기 › 다른 곳에서 부르는 이름으로 옮겼어요.
- ‘기본’ 탭 이름을 **이해하기**로 바꿨어요. 헷갈리는 짝은 한 덩어리로 묶었어요: 짝을 고르면 두 그림 · 가르는 한 줄 · ‘카드 열기’가 같이 바뀌어요. 같은 내용이 세 번 나오던 것을 한 번으로 줄였어요.
- 만들기 탭은 제목 다섯 개를 셋으로 줄였어요. AI 프롬프트는 한 상자에, 잘 만드는 법과 흔한 실수는 **만들 때 확인할 것** 하나에(✓ 하기 · ✕ 하지 않기), 코드 · 그림 가져가기는 접어 뒀어요.
- 더 알기 탭에서 바꿔 달라는 문장 · 우리 팀 이름 · 실제 예시 찾기는 **일할 때 쓰는 도구** 안에 접어 뒀어요.
- 상세 창의 글자 버튼이 위 글과 시작선이 어긋나던 것을 맞췄어요.

### 고침
- 카드 상세 창 › 다른 곳에서 부르는 이름: ‘없음과 배너 알림으로 대신’처럼 어색하던 문구를 ‘따로 없어요 (배너 알림으로 대신)’로 고쳤어요.

## [0.5.0] - 2026-11-17

### 다듬음 (14차 · 더 명료하게 · 읽기 쉽게)
ECC 스킬(make-interfaces-feel-better)과 Stageshow 가독성 기준으로 사이트 전체를 손봤어요.
- **움직임 범위**: `transition: all`을 쓰던 4곳(체험관 스위치, 안내 구멍 · 말풍선)을 바뀌는 속성만 움직이게 고쳤어요.
- **줄바꿈**: 제목은 줄 길이를 고르게(`text-wrap: balance`), 본문은 마지막 줄에 한 단어만 남지 않게(`text-wrap: pretty`) 했어요.
- **줄 길이와 간격**: 설명 문단은 한 줄이 약 40자를 넘지 않게 하고, 본문 줄 간격을 1.6으로 맞췄어요.
- **숫자**: 내 서랍 개수, 서랍 칩 숫자, 퀴즈 점수, 미션 시간처럼 바뀌는 숫자는 자리 폭을 고정해서 흔들리지 않아요.
- **카드**: 영어 이름을 12px에서 13px로 키웠어요.
- **누름 느낌**: 버튼과 칩을 누르면 살짝 눌려요. 움직임 줄이기를 켜면 눌리지 않아요.
- **사진**: 화면에 이름표 붙이기의 사진에 옅은 테두리를 둘러 바탕과 섞이지 않게 했어요.
- **앱 아이콘 · 로고**: 탭 아이콘과 앱 아이콘이 예전 디자인(남색 · 주황)이었고, 아이콘을 만드는 스크립트가 그림을 확대해 잘린 채로 찍고 있었어요. 지금 사이트 로고(청록 서랍)로 바꾸고 제대로 찍히게 고쳤어요. README 맨 위 로고도 이 아이콘이에요.
- **체험관 더보기 메뉴**: 메뉴가 아래 체험 창 뒤로 깔려 ‘미션 모드’만 반쯤 보이던 것을 고쳤어요. 이제 창 위로 온전히 뜨고, 메뉴 밖을 누르거나 Esc를 누르면 닫혀요.
- **사전**: 선택된 칩과 큰 제목이 이미 위치를 알려 줘서, 겹치던 ‘사전 › UI 부품 › 서랍’ 줄을 뺐어요.

### 다듬음 (13차 · 단순하게)
기능이 늘면서 화면마다 고를 것이 너무 많아져서, 아무것도 지우지 않고 자주 쓰는 것만 앞에 두고 나머지는 한 겹 안으로 넣었어요.
- **메뉴**: 왼쪽 아래 작은 메뉴를 6개에서 3개(빠른 이동 · 내 서랍 · 테마)로 줄였어요. 비교는 카드를 담았을 때만 아래 띠로 나오고, 새 소식 · 비교 · 언어는 내 서랍 설정 탭으로 옮겼어요.
- **홈**: 배너 · 바로가기 3개 · 오늘의 카드만 남겼어요. 내 서랍 상자, 새 카드 10장 목록, 제안 양식은 맨 아래 한 줄 링크(새 카드 보기 · 없는 UI 제안하기)로 줄였어요.
- **카드 상세 창**: 위쪽 아이콘을 이전 · 다음 · 닫기 셋으로 줄이고, 소리로 듣기는 더보기 메뉴로 옮겼어요. 코드 복사 버튼 7개는 ‘형식 고르기 + 복사 + 그림 내려받기’로 합쳤어요.
- **배우기**: 보기 10개를 ‘익히기(2) · 문제 풀기(3) · 더 해 보기(5)’로 나눠, 처음에는 2개만 보여요.
- **체험관**: 도구 줄을 사이트 · 더보기 · 이름표 셋으로 줄였어요. 미션 · 스타일 · 상황 · 잘못 만든 버전은 더보기 안에 있고, 무언가 켜져 있으면 더보기에 점이 떠요.
- **이름표**: 단계 3개와 버튼만 바로 보이고, 추가하는 방법 · 휴대폰에서 쓰기 · 내 규칙은 접어 뒀어요.

### 더함 (12차 · 기능 14가지)
- **카드 링크 미리보기**: 빌드할 때 카드마다 `c/<카드>.html`을 만들어요. 카톡이나 슬랙에 카드 링크를 붙이면 그 카드 그림과 설명이 같이 떠요. 그림 주소를 완전한 주소로 쓰려면 `SITE_URL=https://사이트주소/`를 주고 빌드해요. 대표 그림(og.png)도 지금 첫 화면으로 다시 찍었어요.
- **검색 동의어 60개 더**: ‘아래서 올라오는 창’, ‘회색 박스 로딩’, ‘밀어서 삭제’처럼 사람들이 실제로 쓰는 말로도 찾아져요.
- **나란히 보기 주소** `#/vs/카드/카드`: 두 카드를 크게 나란히 띄워요. 링크로 보내거나 좌우를 바꿀 수 있어요. 카드 상세 창의 더보기와 배우기 짝 카드에서 들어가요.
- **한 줄로 가르기**: 자주 헷갈리는 짝 24쌍마다 구분법을 한 줄로 정리했어요. 상세 창, 배우기 짝 카드, 퀴즈 해설, 나란히 보기에 보여 줘요.
- **들른 날 잔디**: 내 서랍 기록 탭에 최근 8주 동안 들른 날을 보여 줘요.
- **틀린 것만 다시**: 배우기 › 문제 풀기에서 오답 노트의 카드로만 퀴즈를 내요. 맞히면 노트에서 빠져요.
- **소리로 듣기**: 상세 창에서 카드 이름과 설명을 읽어 줘요(브라우저 기본 음성).
- **화면에 이름표 붙이기** `#/annotate`: 내 화면 사진에 카드 이름표를 눌러 붙이고, 끌어서 옮기고, 그림으로 내려받아요. 사진은 브라우저 밖으로 나가지 않아요.
- **우리 팀은 이렇게 불러요**: 카드마다 팀에서 부르는 이름을 적어 두면, 그 이름으로 검색해도 그 카드가 먼저 나와요.
- **피그마용 SVG 복사**: 상세 창 만들기 탭에서 복사해 피그마에 그대로 붙여 넣어요.
- **체험 사이트 2곳 더**: 문서 편집기 ‘몽글 문서’(서식 줄, / 명령, 댓글, 함께 보는 사람, 버전 기록, 목차, 자동 저장, 동기화, 되돌리기)와 길 찾기 ‘몽글 지도’(정확한 위치 묻기, 내 위치, 미니맵, 혼잡도 지역 색, 단계 진행)를 더해 사이트 12곳, 체험 176개가 됐어요.
- **잘못 만든 버전 보기**: 체험관 어느 사이트든 일부러 불편하게 바꿔 보고, 어디가 불편한지 찾아본 뒤 답을 볼 수 있어요.
- **Stageshow 짝 비교 그림**: 모달과 바텀시트, 툴팁과 팝오버, 체크박스와 토글을 같은 행동으로 비교해요. 나란히 보기에서 그 짝일 때 보여요. PC는 창 하나를 반으로, 휴대폰은 휴대폰 화면을 위아래로 나눠요.
- **Stageshow 새 소식 그림**: 새 카드가 하나씩 서랍에 들어오고 카드 수가 올라가요. 한 번만 재생해요.

### 다듬음 (11차 · Stageshow 기준 가독성 · 정렬)
- **카드 그림 가독성**: 보이는 크기로 글자를 재는 `npm run readable`을 만들었어요. 처음에 226건이 나왔어요(작은 글자 80, 흐린 글자 126, 줄 간격 15, 가짜 화면 속 제목 태그 5). 일부러 그렇게 그린 카드와 측정 오류를 빼면 남은 건 0건이에요.
  - 아주 작던 글자 38곳에 최소 크기를 줬어요(예: 달력 · 카운트다운 · 리본).
  - 옅은 회색과 초록 글자를 진하게 바꿨어요. 별점, 안 읽음 숫자, 아바타, 레이어, 트리맵 글자 색도 고쳤어요.
- **가짜 화면 안의 제목 태그**: 체험 사이트들의 h2~h4 25곳을 일반 글자로 바꿨어요. 가짜 앱 제목이 실제 페이지 목차에 섞이지 않아요.
- **Stage 그림 5개**: 멈출 때 글자 흔들림, 어긋난 글자 시작선, 2px로 붙은 요소, 잘린 토스트, 글자보다 작은 버튼, 좌우 여백이 다른 버튼, 글자를 가리는 커서를 고쳤어요. PC와 휴대폰 모두 경고 없이 통과해요(`개발/docs/REHEARSAL.md`).
- **정렬**: 상자 안쪽 여백을 한 값(PC 32px, 휴대폰 16px)으로 맞췄어요. 글자 버튼은 위 문단과 글자 시작선이 같도록 당겼어요. ‘오늘의 카드’ 설명은 안내 문장과 기록 숫자로 나눠 두 줄로 보여 줘요.

### 고침 (10차 · 사이트 전체 점검 두 번)
- **전체 점검 도구** `npm run audit`를 만들었어요. 화면 23곳과 체험 사이트 10곳을 PC, 휴대폰, 휴대폰 다크 모드로 열어서 콘솔 오류, 가로 넘침, 이름 없는 버튼, 잘린 글자, 너무 작은 누르는 곳, 겹친 id를 찾아요. 1차에서 32건이 나왔고, 고친 뒤 2차는 0건이에요.
- 점검표에서 같은 카드가 두 묶음에 들어가 경고가 나던 것을 고쳤어요.
- 휴대폰에서 홈 아래쪽 링크와 ‘오답 노트’ 링크를 누르기 쉽게 키웠어요.
- 닫힌 상세 창이 화면 높이가 바뀔 때 잠깐 비쳐 보이던 것을 고쳤어요.
- 검색 결과 없음 상자의 정렬을 왼쪽으로 맞췄어요.
- 배우기 맨 위 ‘가장 많이 헷갈리는 짝’ 소개는 ‘헷갈리는 짝’ 보기에서만 나와요.
- ‘자동’ 테마일 때 해와 달이 같이 있는 아이콘이 나와요.
- 섹션 제목 옆 설명을 제목 아래 줄로 내려서 좁은 화면에서 어중간하게 꺾이지 않아요.
- 말투: ‘이럴 때 써요’ 항목 601개, 잘 만드는 법, 접근성 점검표, 새 소식 설명을 끝맺는 문장으로 다듬었어요.

### 다듬음 (9차 · 쓰기 편하게 · 말투)
- **더 단순하게**
  - 카드 상세 창을 ‘기본’, ‘만들기’, ‘더 알기’ 탭으로 나눴어요. 아래 버튼은 체험관에서 보기, 폴더에 담기, 비교만 두고 나머지는 더보기(⋯)에 넣었어요.
  - 배우기의 보기 아홉 개를 ‘익히기’와 ‘문제 풀기’ 두 묶음으로 나눴어요.
  - 내 서랍을 ‘모은 것’, ‘기록’, ‘설정’ 탭으로 나눴어요.
  - 체험관의 사이트 버튼 11개를 ‘사이트’ 메뉴 하나로 줄였어요.
  - 홈에서 ‘서랍 둘러보기’를 빼고, 바로가기 세 개를 위로 올렸어요.
- **길 찾기**
  - 다른 화면으로 가면 상세 창이 닫혀요. 휴대폰에서 뒤로 가기를 누르면 사이트를 떠나지 않고 창부터 닫혀요.
  - 전에 보던 화면으로 돌아오면 보던 자리로 돌아가요. 사전 위에 ‘사전 › UI 부품 › 서랍’ 위치가 보여요.
  - 검색 결과가 없으면 생김새로 찾는 예시, 비슷한 카드, 새 카드 제안 링크를 함께 보여 줘요.
  - 빠른 이동(⌘K · Ctrl+K)으로 카드, 화면, 설정을 한 칸에서 찾아요.
  - 상세 창에서 이전 · 다음 카드로 넘길 수 있어요. 키보드 좌우 화살표, 휴대폰에서는 그림을 옆으로 밀면 돼요.
- **처음 온 사람**: 홈에 세 걸음 안내를 한 번만 보여 줘요. 빈 화면은 어디서나 ‘무엇이 없는지 · 어떻게 채우는지 · 갈 곳’ 모양으로 맞췄어요.
- **휴대폰**: 상세 창이 반쯤 열린 바텀시트로 떠요. 손잡이를 누르거나 위로 끌면 끝까지 열려요. 누르는 곳은 44px 넘게 키웠어요.
- **알림**: 복사, 담기, 내려받기를 화면 아래 스낵바 하나로 알려요. 되돌릴 수 있는 일에는 ‘실행 취소’가 붙어요. 기록이 어디에 저장되는지 설정 탭에 한 번에 적었어요. 화면을 불러오는 동안 회색 뼈대를 먼저 보여 줘요.
- **접근성 · 일관성**: 움직임 줄이기를 켜면 반복 움직임까지 멈춰요. 키보드 초점 표시를 어디서나 같게 했어요. 말투 · 용어 기준(`개발/docs/말투-기준.md`)을 만들고 화면 글을 그에 맞게 고쳤어요.
- **말투**: 화면 글과 카드 설명에서 화살표와 가운뎃점으로 이은 문장을 평소 말로 바꿨어요(카드 설명 192개). 변천사와 팁도 끝맺는 문장으로 다시 썼어요.
- **실제로 써 보고 확인**: 사용성 시험 모드(`#/test`)를 넣었어요. 과제 다섯 개를 차례로 주고, 걸린 시간과 거쳐 간 화면을 기록해서 표로 복사할 수 있어요. 개발 서버에서는 화면마다 머문 시간도 보여 줘요.
