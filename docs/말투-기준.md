# UI Drawer 말투 · 용어 기준

화면에 글을 새로 쓰거나 고칠 때 이 기준을 따라요.

## 문장
- 문장은 ‘~요.’로 끝내고 마침표를 찍어요. 제목, 버튼, 목록의 짧은 항목은 마침표 없이 써요.
- 화살표(→)나 가운뎃점(·)으로 문장을 잇지 않아요. ‘A와 B’, ‘A, B, C’처럼 말로 이어요.
  - 가운뎃점은 짧은 꼬리표나 메뉴 이름에서만 써요. (예: ‘창 · 확인’)
- 괄호 속 덧말은 되도록 따로 한 문장으로 빼요.
- ‘제공합니다’, ‘활용하세요’, ‘직관적인’ 같은 딱딱한 말 대신 평소에 쓰는 말로 써요.

## 알림
- 방금 한 일은 화면 아래 스낵바 하나로 알려요. 무엇을 했는지 한 문장으로 쓰고, 되돌릴 수 있으면 ‘실행 취소’를 붙여요.
  - 예: ‘비교에 담았어요.’, ‘공유 링크를 복사했어요. 받은 사람이 열면 이 폴더를 담을 수 있어요.’
- 입력이 틀렸을 때는 그 칸 바로 아래에 빨간 글자로 알려요.

## 빈 화면
‘무엇이 없는지 + 어떻게 채우는지 + 갈 곳 하나’를 같이 보여 줘요.
- 예: ‘아직 비어 있어요.’ / ‘마음에 드는 카드를 열고 폴더에 담기를 눌러 보세요.’ / [사전 둘러보기]

## 같은 일은 같은 말로
| 하는 일 | 쓰는 말 | 쓰지 않는 말 |
|---|---|---|
| 폴더 · 비교에 넣기 | 담기 · 빼기 | 추가 · 삭제 · 저장 |
| 파일로 받기 | 내려받기 | 다운로드 · 내보내기 |
| 파일을 다시 넣기 | 파일 넣기 | 가져오기 · 업로드 |
| 주소 · 코드 복사 | ~ 복사 | 복사하기 · 카피 |
| 카드 보기 | 카드 열기 · 보기 | 들어가기 |
| 북마크 · 내 규칙 | 더하기 | 등록 |

## 버튼
- 한 화면(또는 한 덩어리)에서 꼭 눌러야 할 버튼 하나만 채운 버튼(초록 바탕)으로 만들어요.
- 나머지는 글자 버튼으로, 잘 안 쓰는 것은 ‘더보기(⋯)’ 메뉴에 넣어요.
- 손가락으로 누르는 곳은 44px 넘게 만들어요.
